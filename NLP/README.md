# Natural Language Processing

Revision notebooks covering the processing and modeling of human language.

## Topics

- `01_foundations`: Language data, tokenization, and linguistic basics
- `02_text_preprocessing`: Cleaning, normalization, vectorization, and datasets
- `03_embeddings`: Count vectors, TF-IDF, word embeddings, and representations
- `04_sequence_models`: N-grams, RNNs, LSTMs, and sequence classification
- `05_transformers`: Attention, transformer architectures, and modern NLP workflows
- `06_projects`: Larger exercises that combine multiple NLP concepts

Add notebooks in learning order and use numbered `snake_case` filenames.
