# Reinforcement Learning

Revision notebooks covering learning through interaction with an environment.

## Topics

- `01_foundations`: Agents, environments, rewards, returns, and Markov decision processes
- `02_dynamic_programming`: Policy evaluation, policy improvement, and value iteration
- `03_monte_carlo`: Episode-based prediction and control methods
- `04_temporal_difference`: TD learning, SARSA, and Q-learning
- `05_deep_rl`: Function approximation and neural reinforcement learning
- `06_projects`: Larger exercises that combine multiple RL concepts

Add notebooks in learning order and use numbered `snake_case` filenames.
