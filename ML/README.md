# Machine Learning

Revision notebooks covering core machine learning concepts, algorithms, and evaluation.

## Topics

- `01_foundations`: Data, features, probability, linear algebra, and preprocessing
- `02_supervised_learning`: Regression, classification, trees, and nearest neighbors
- `03_unsupervised_learning`: Clustering, dimensionality reduction, and anomaly detection
- `04_ensemble_methods`: Bagging, boosting, and random forests
- `05_model_evaluation`: Metrics, validation, calibration, and model selection
- `06_projects`: Larger exercises that combine multiple ML concepts

Add notebooks in learning order and use numbered `snake_case` filenames.
